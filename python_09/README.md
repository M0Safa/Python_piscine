## INTRODUCTION
This project is designed to introduce us to the `BaseModule` class and show how to define and control its attributes using `Field`. It also demonstrates how to apply validation 
rules using the `validator method`, and how to use `Enum` to manage fixed sets of values for attributes, ensuring that the model is both structured and error-free.

## Exercises Overview

### Exercise 0
  This exercise introduces us to creating a `BaseModule` and demonstrates how to use `Field` to apply constraints to the `space_station` attribute.


### Exercise 1
   In this exercise, we learn how to add a `validator method` to enforce conditions after a module is created, and how to use `Enum` to define a fixed set of communication types.
### Exercise 2
  Finally, in the last exercise, we learned how to use `nested models` by creating a `Crew` model and including a list of crew members inside the `SpaceMission` model.
