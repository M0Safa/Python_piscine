# Introduction
This project teaches us, through each exercise, how to implement a specific function that we will see in the 
next paragraphs.
## exercise 0
In this exercise, we explore `lambda` functions, which are small anonymous functions defined using the lambda 
keyword. They can take any number of arguments but consist of a single expression, making them ideal for 
simple operations without creating a full function.
## exercise 1
In this exercise, we learn how to implement a `higher-order function` — a function that takes another function 
as an argument and returns a ew function as its result. This demonstrates an important concept in 
functional programming, where functions are treated as `first-class objects`.
## exercise 2
In this exercise, we explore the use of the `nonlocal` keyword in Python. The nonlocal keyword allows a nested 
function to modify a variable defined in its enclosing scope, rather than creating a new local variable.
## exercise 3
In this exercise, we explore several useful tools from Python’s `functools` module. `reduce` allows us to 
combine elements of a sequence into a single value, `partial` lets us fix some arguments of a function to 
create a simpler version, `lru_cache` caches function results to improve performance for repeated calls, and 
`singledispatch` enables a function to behave differently based on the type of its first argument.
## exercise 4
In this exercise, we explore decorators, which are functions that wrap other functions to modify or extend their 
behavior without changing their original code. Decorators can be used for logging, timing, caching, or adding 
authentication, among other purposes.
