# Python_piscine

## Introduction

The Python Piscine consists of 11 modules, each focused on a key concept in Python development. The program aims to equip students with strong foundational knowledge and hands-on experience, preparing them for 
more complex and advanced projects in the future.

### Module 00

This module aims to introduce Python and its essential built-in functions, such as `print()`, along with the fundamental syntax needed to start programming.

### Module 01

This module introduces `object-oriented programming` in Python, focusing on how to create classes and methods, and how to integrate them into a structured program.

### Module 02

This module introduces the use of `try` and `except` blocks for error handling, and explains how to raise exceptions and create custom error types.

### Module 03

This module explores Python’s built-in data structures — lists, dictionaries, sets, and tuples — and demonstrates how they can be used for efficient data organization and manipulation.

### Module 04

This module introduces file handling in Python, focusing on how to `open` files and perform `read` and `write` operations safely and efficiently.

### Module 05

This module explores `class inheritance` in Python, demonstrating how child classes can inherit attributes and methods from parent classes to promote code reuse and better program structure.

### Module 06

This module focuses on Python’s `import` system, explaining how to import functions and classes from different files and directories to structure and organize projects properly.

### Module 07

This module consolidates all the concepts learned throughout the modules by implementing a complete card game application, demonstrating practical use of Python fundamentals.

### Module 08

This module introduces Python `virtual environments` and package management, covering tools like `pip` and `poetry` for installing, managing, and organizing project dependencies.

### Module 09

This module introduces the use of a `BaseModul`e and `Field` to define and build specific structured data models in Python, enabling validation and organized data handling.

### Module 10

This module examines Python functions in depth, including defining and using regular functions, `lambda` expressions, and higher-order functional constructs.
